# 대안 비교: 삭제 경로별 비용·위험 (2026-09-17)

## 정액제 서비스가 가능한 이유
- 큐비: 2023년까지 공식 API 앱(Sign in with Twitter) → API 유료화로 중단 → 2026-01 크롬 확장으로 복귀(사용자 2만, 2026-08-25 갱신). "데이터는 브라우저 밖으로 나가지 않음", 아카이브로 대상 열람
- 즉 삭제 요청은 사용자의 로그인된 x.com 세션에서 웹 클라이언트 내부 엔드포인트로 나감 → 운영자의 API 비용 0 → 건수와 무관한 정액 요금 가능
- Cyd(오픈소스 데스크톱, 삭제 무료·필터는 $36/년): 내장 브라우저에 프로필을 띄우고 JavaScript를 반복 실행. X 한도에 걸리면 15분 미만 대기
- TweetDeleter·Circleboom 등 해외 정액 서비스: Enterprise API(월 $42,000~)를 수만 사용자에 분산 → 개인은 불가

## 공식 API에서 실제로 줄일 수 있는 것
- 없는 것: 정액·할인 티어(2026-02 폐지), 삭제 무료 경로. 신규 계정 체험 크레딧 $1(≈100~200건)만
- 있는 것: ① 건수 감축(RT 제외, 보존 필터, 단계적 삭제) ② 열람 $0(아카이브) ③ 단가 확인(`Content: Manage` $0.005면 3만 건 $150) ④ 비용 상한으로 예산 통제
- 결론: 비용은 건수 × 단가로 선형. 안전(공식 경로)과 비용(세션 경로)은 교환 관계
