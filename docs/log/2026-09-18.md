# 2026-09-18 · 스윕 보존 필터 (T35)

## 배경

- ADR-0009는 스윕을 "전부 삭제, 필터 없음"으로 정했었다 → ADR-0010으로 개정

## 결정한 것
- **스윕 모드 전용**(사용자 확정). 명세의 '내가 좋아요/리트윗/북마크한'은 아카이브에 없는 정보다(legacy `favorited`·`retweeted`는 아카이브에서 항상 false). 8개 조건을 모두 판정할 수 있는 곳은 타임라인 카드 DOM뿐
- **멘션 = 답글 카드 + 본문이 @로 시작**(사용자 확정). X는 답글 카드에서 맨 앞 @핸들을 본문에 넣지 않고 "…에게 보내는 답글"로 따로 그린다. 명세 문구("@로 시작")만 따르면 실제 답글이 대부분 안 잡힌다
- 수치는 **파싱하지 않는다**. 명세가 요구하는 건 "1개 이상"뿐이고, 버튼 `aria-label`에 숫자가 있는지만 보면 축약 표기("1.2천")·로캘에 흔들리지 않는다

## 알게 된 것 / 함정
- **완료 판정이 깨질 뻔했다.** 보존한 글은 안 지워지므로 타임라인 맨 위에 영구히 쌓인다. 기존 사다리(스크롤 3 → 새로고침 → 스크롤 3 → 완료)는 보존 글 벽이 세 화면만 넘어도 거짓 완료로 멈춘다 → 스캔에 처음 보는 글이 있으면 빈 횟수를 0으로 되돌리고, 이번 실행에서 본 id를 전부 기억해 새로고침 후를 "새 카드"로 오인하지 않게 함
- 필터가 켜져 있으면 삭제 후 맨 위로 되돌아가지 않는다. 돌아가면 보존 글 벽을 매번 다시 스크롤해야 하고 그 비용이 삭제할수록 커진다
- 답글 판정은 액션 바를 먼저 떼어내야 한다. "답글 3개" 버튼이 모든 카드에 있어 그냥 `/답글/`로 보면 전부 답글이 된다. 본문(`tweetText`)도 함께 제거(본문에 "답글"이 들어갈 수 있음)
- `<fieldset disabled>` 안의 input은 `input.disabled`가 여전히 false다(IDL 속성은 자기 attribute만 반영). 테스트는 fieldset을 봐야 한다
- 확장 대시보드는 브라우저로 바로 못 여니, 컴포넌트를 정적 HTML로 뽑아 실제 CSS를 입히고 localhost로 띄워 눈으로 확인했다(`file://`은 도구가 거부)

## 질주 프리셋과 기록 본문 (T36, 같은 날)

### 배경
- 사용자: "너무 느리다, 정지 위험이 높더라도 2초 옵션을 넣어라" + "무슨 트윗이 지워졌는지 알게 본문을 실시간 기록에 붙여라"

### 느렸던 진짜 이유
- 플로어(5초)가 아니라 **간격을 창 전체에 고르게 분산하는 산식** `W ÷ (u·L)`였다. 실측 L=200/15min에서 `brisk`는 6.4초, 게다가 첫 100건은 워밍업 u=0.3이라 약 15초
- 그래서 플로어만 2초로 낮췄으면 `Math.max`에 걸려 **아무것도 달라지지 않았을 것**이다 → `burst` 플래그로 분산 산식·워밍업·긴 휴식을 함께 건너뛴다(ADR-0011)

### 정직하게 남길 것
- **하루 총량은 거의 안 늘어난다.** 예산은 서버가 창 단위로 준다. 2초로 달리면 약 380초 만에 창을 비우고 리셋까지 멈춘다. brisk ≈7,840/14h vs rush ≈10,640(일일 상한 8,000에서 잘림)
- 실이득은 ① u 0.7→0.95로 창 예산을 더 씀 ② 짧은 세션 체감(30분 약 281 → 약 380건). 설정 화면에 배너로 띄웠고 `estimate()`도 간격이 아니라 창 예산으로 세도록 고쳤다(간격만 세면 25,200건으로 과대평가)

### 함정
- 하드 최소를 2초로 낮추면 지터 하한도 같이 풀려 **신중·보통·빠름의 실질 최저 간격까지 5초→2초**가 된다. 요청은 새 옵션 추가지 기존 프리셋 완화가 아니므로, 지터 하한을 하드 최소가 아니라 프리셋 플로어(`floorMsOf`)로 바꿨다
- u를 1.0으로 두면 `shouldWaitForReset`이 영영 발동하지 않아 429를 정통으로 맞고, 사다리 3회면 다음 날까지 정지라 오히려 느려진다 → 0.95로 잔여 10건을 남긴다
- 4% 긴 휴식은 2초 간격에서 평균 +1.2초, 속도 이득의 60%를 먹는다 → 폭주 모드만 생략. 로그노멀 지터는 평균 +6%뿐이라 유지(정확히 2.000초는 가장 탐지하기 쉬운 패턴)
