# ADR-0001: 삭제 경로 — 로그인 세션 기반 브라우저 확장(무료). 공식 API 대신

- 상태: 확정 · 2026-09-17 · `tweet-sweep` ADR-0001(공식 API만)을 대체

## 맥락
- 공식 API는 종량제만 남아 3만 건 기준 $150~300. 큐비·Cyd 등은 사용자 세션에서 실행해 API 비용 0(큐비는 서비스료 7,900원/월·계정)
- 사용자 결정: "큐비와 똑같은 방식으로 무료로. 계정 정지 위험이 조금 올라가도 수용"

## 결정
- 사용자 Chrome에 설치되는 확장 프로그램이, 이미 로그인한 x.com 세션 안에서 삭제 수행
- 공식 API·토큰·개발자 계정 사용 안 함. 서버 없음
- `tweet-sweep`(공식 API 설계)은 보류 상태로 보존. "유료·최저 위험" 대안으로 복귀 가능

## 이유
- 비용 0. 아카이브 열람과 결합하면 API 비용도 구독도 없음
- 동종 도구(큐비 사용자 2만, Cyd 오픈소스)가 수년간 같은 방식으로 운영 → 실행 가능성 검증
- 자체 구현이면 페이싱을 시중 도구보다 훨씬 보수적으로 잡고, 세션을 제3자 코드에 맡기지 않음

## 수용한 위험 (P0)
| 위험 | 정도 | 완화 |
|---|---|---|
| 약관 위반 소지(비공개 인터페이스 자동화) | 상존 | 본인 글 삭제 한정. 속도 최소화 |
| 일시 차단(429, 15분 내) | 흔함 | 회로차단 후 대기. 다음 세션 속도 하향 |
| 계정 잠금(전화 인증) | 낮음~중간 | 스파이크 없는 저속·활동 시간대·워밍업. 잠금 시 사람이 해제 후 재개 |
| X 웹 클라이언트 변경으로 파손 | 주기적 | 실행기 2종 추상화, 셀렉터·식별자 설정화, 계약 테스트 |

## 대안과 기각 사유
| 대안 | 기각 사유 |
|---|---|
| 공식 API(tweet-sweep) | 비용 $150~300. 사용자가 비용 우선 |
| 큐비·Cyd 그대로 사용 | 학습 목표 미달. 큐비는 비공개 코드에 세션 위임 |
| 데스크톱 앱(Electron, Python+Playwright) | 별도 브라우저 프로필 = 새 기기 로그인 신호. 사용자 요청은 확장 형태 → ADR-0002 |
