# ADR-0003: 열람은 데이터 아카이브, 계정 일치는 `twid` 쿠키로 검증

- 상태: 확정 · 2026-09-17 · `tweet-sweep` ADR-0003 계승

## 맥락
- 세션에서 GraphQL로 내 글을 열람(UserTweets)하면 페이지네이션이 깊고 오래된 글·답글은 누락되기 쉬움. 요청 수도 늘어남
- 사용자는 계정별 아카이브 zip 보유

## 결정
- 대상 열람은 아카이브 `tweets.js`(+parts) 파싱. 확장 UI에서 파일 선택으로 가져오기(로컬)
- 아카이브 `account.js`의 accountId와 현재 세션 `twid` 쿠키의 사용자 id가 다르면 실행 거부
- 아카이브 시점 이후 게시물은 v1 범위 밖(추후 프로필 스캔 실행기로 보충 가능)

## 이유
- 전체 이력·답글 포함, 요청 0건. 열람 요청 자체가 이상 신호가 될 여지 제거
- 다른 계정 아카이브로 실행하는 사고 방지

## 대안과 기각 사유
| 대안 | 기각 사유 |
|---|---|
| 프로필 스크롤 수집 | 깊은 이력 누락, 요청 다수, 느림 |
| GraphQL UserTweets 열람 | 위와 동일 + 식별자 회전 의존 |
